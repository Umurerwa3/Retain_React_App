# Retain

Retain is a personal expense and budget manager. Users record their expenses, set a monthly budget and track how much of it they have spent. Admins manage expense categories and view platform-wide insights.

The project is split into two parts:

- `client/` – React + TypeScript frontend built with Vite
- `server/` – Node.js + Express REST API backed by MongoDB

> Setup instructions, features and API docs will be added as the project grows.
